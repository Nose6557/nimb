# NIMB — щоденник головного болю

Швидкий запис головного болю, статистика і прогноз ризику на завтра за погодою,
магнітними бурями й станом повітря. Інтерфейс українською. Стиль — як у NIVO:
системні сірі й кольори Apple, Unbounded + IBM Plex Sans, акцент Indigo, темна і світла теми.

## Що вміє (версія 1)

- **Швидкий запис.** Кнопка «Болить» створює запис з поточним часом. Далі — сила 0–10,
  де болить, таблетки, тригери, нудота, нотатка. Поки біль триває, на головній є таймер,
  «+ Цитрамон», питання «Таблетка допомогла?» через 40 хв і кнопка «Минуло».
- **Сьогодні без болю.** Відмітка в один тап. Такі дні роблять прогноз точнішим.
- **Історія** з пошуком, редагуванням і видаленням.
- **Статистика:** головні числа, епізоди по місяцях, календар, «що впливає саме на тебе»,
  час початку, тригери, день тижня, таблетки. Попередження, якщо таблетки 10+ днів за 30.
- **Прогноз** на сьогодні, завтра й післязавтра.
- **Імпорт** CSV з Notion (колонки «Дата», «Назва / Опис», «Інтенсивність», «Нотатки»).
  Час, тригери, таблетки й «допомогло» визначаються з тексту. Дати, на які вже є запис, пропускаються.
- **Експорт** CSV і JSON.
- **Акаунт** (пошта + пароль) або гостьовий режим. Записи гостя переносяться в акаунт після входу.
- **Тема:** системна, світла, темна. **Місце:** геолокація або місто вручну.
- **PWA:** встановлюється на телефон, оболонка працює офлайн.

## Як працює прогноз

1. Функція Supabase `env` збирає дані по днях для твого місця:
   тиск і його зміна за добу, температура, вологість, опади, вітер (Open-Meteo),
   PM2.5 і AQI (Open-Meteo Air Quality), максимальний Kp (GFZ Potsdam + NOAA SWPC, з прогнозом на 3 дні).
2. Базова частота — частка днів з болем від першого запису.
3. Для кожного фактора рахується, у скільки разів частіше болить у дні з ним.
   Поки таких днів мало, оцінка тягнеться до загальновідомого значення.
4. Ризик дня — базова частота × відношення факторів, які підвищують ризик.
   До 1,3× — низький, до 2× — середній, далі — високий.

Прогноз — підказка, а не медичний висновок.

## Структура

| Файл | Що робить |
|---|---|
| `index.html` | Розмітка всіх екранів і листів |
| `style.css` | Токени тем і стилі компонентів |
| `version.js` | Версія оболонки (кеш service worker) |
| `config.js` | URL і publishable-ключ Supabase, місце за замовчуванням |
| `store.js` | Єдиний доступ до даних: Supabase або localStorage |
| `tags.js` | Словники міток, CSV, розбір тексту з Notion |
| `env.js` | Місце, кеш погоди, аналіз факторів, ризик |
| `charts.js` | Графіки на SVG |
| `app.js` | Екрани, навігація, відмальовування |
| `sw.js`, `manifest.json`, `favicon/` | PWA |
| `supabase/migrations/` | SQL таблиць і RLS |
| `supabase/functions/env/` | Функція даних довкілля |

## Supabase

Проєкт **Headache Diary** (`iwfbclwxateylglzwioo`, Франкфурт).
Таблиці: `profiles`, `episodes`, `ok_days`, `env_daily` (заготовка). Усі під RLS.
Функція `env` — публічний проксі погоди без даних користувачів (`verify_jwt = false`).

## Запуск локально

```sh
python3 -m http.server 8788
```

Відкрити `http://localhost:8788`. Через `file://` не працює.
