# NIMB — пам'ятка для Claude

Щоденник головного болю з прогнозом ризику. Опис — у [README.md](README.md).

## Мова
- Спілкування, коміти, коментарі, тексти інтерфейсу — українською.
- Коміт — одне коротке речення про зроблене. Без префіксів `feat:`.

## Стек
- Чистий HTML/CSS/JS без збірки і фреймворків, як у NIVO. Модулів і бандлера не додавати.
- Порядок скриптів: `version.js` → `config.js` → `store.js` → `tags.js` → `env.js` → `charts.js` → `app.js`.
- Дані — тільки через `store.js`. У `config.js` лише publishable-ключ, секретів у репо немає.
- Кольори — лише через семантичні токени в `style.css`. Нова тема = нові значення тих самих токенів.

## Під час правки
- Змінився статичний файл — бампни `NIMB_VERSION` у `version.js`; новий файл — додай у `SHELL` в `sw.js`.
- Змінилися колонки Supabase — допиши міграцію в `supabase/migrations/`.
- Змінилася функція `env` — онови файл у `supabase/functions/env/` і задеплой.
- Перевірка — жива сесія в браузері в обох темах: імпорт CSV, «Болить», «Минуло», статистика, експорт.
